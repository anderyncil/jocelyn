# Flores amarillas

Página 3D interactiva lista para publicar en GitHub Pages. Requiere conexión a Internet al abrirse porque carga la librería Three.js desde un CDN.

1. Sube todos los archivos del proyecto (incluida la carpeta `assets`) a un repositorio de GitHub.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/(root)`.
4. Guarda los cambios. GitHub mostrará el enlace público en esa misma pantalla.

Puedes personalizar los cumplidos editando la lista de palabras al final de `script.js`.
